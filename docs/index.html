セキュリティと運用

  • 起動用パスフレーズ・自動ロックはありません。iPhoneのパスコード・Face IDで端末を保護してください。
  • 名簿・受付日時は端末に保存した暗号鍵で暗号化し、自動で開きます。
  • 受付確定は保存完了後に表示。二重受付を検出します。
  • QRの転送やスクリーンショットは防げません。表示された氏名を本人と確認してください。
  • サイトデータの削除・アプリ削除・端末故障に備え、暗号化バックアップを保管してください。
